# 2026-08-10

## 小程序登录页改造（chooseAvatar + nickname 输入）
- 新建 `pages/login/login.{js,wxml,wxss,json}` 登录页，作为小程序入口页（app.json pages 首位）。
- 头像：`<button open-type="chooseAvatar" bind:chooseavatar="onChooseAvatar">`，回调取 `e.detail.avatarUrl` 临时路径，随即 `wx.cloud.uploadFile` 上传换 fileID；预览用临时路径，提交用 fileID。
- 昵称：`<input type="nickname" bindinput="onNicknameInput">`。
- 登录：`wx.login()` 取 code，与 nickName/avatarUrl 一并 POST `/api/login`；成功后 saveToken + switchTab 首页。
- `app.json` 增加 `requiredPrivateInfos: ["chooseAvatar"]`。
- `utils/api.js` 的 `login(profile?)` 扩展为可携带 nickName/avatarUrl（不传则仅 code，向后兼容）。
- `app.js` 重构：原 `autoLogin` 拆为 `boot()`（启动路由：有 token 且有昵称→switchTab 首页；无 token/缺昵称→留登录页）与 `ensureLogin()`（tabBar 页守卫，未登录缺昵称→reLaunch 登录页）。
- 登录页为入口后，首页 `showSetup` banner 实际不再触发（登录必填昵称），保留为无害死代码。
- 注意：后端 `Login` 对已有昵称的用户不会更新头像/昵称（仅 user.NickName=="" 时更新）；登录页只面向首次/缺昵称用户，无影响。
